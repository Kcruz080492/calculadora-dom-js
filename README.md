# 🧮 Calculadora DOM con JavaScript

Este proyecto forma parte de las prácticas de la asignatura **Programación Estructurada**.  
Su propósito es introducir a los estudiantes al manejo del **DOM (Document Object Model)** mediante un ejercicio sencillo y funcional: una calculadora básica que realiza operaciones aritméticas utilizando JavaScript.

---

## 🎯 Objetivo de aprendizaje
Comprender cómo **JavaScript se comunica con el HTML a través del DOM**, accediendo a los elementos de la página, leyendo los valores ingresados por el usuario y mostrando resultados en tiempo real.

---

## 🧠 Conceptos que se refuerzan
- Acceso a elementos del DOM mediante `getElementById()` y `querySelector()`.  
- Lectura y conversión de valores de entrada (`.value` → `parseFloat()`).  
- Manipulación del contenido del documento con `.textContent`.  
- Uso de **eventos** (`addEventListener`) para responder a las acciones del usuario.  
- Validación básica de entradas y control de errores (como división entre cero).

## 🚀 Instrucciones de uso

1. **Clonar el repositorio**
   git clone https://github.com/Kcruz080492/calculadora-dom-js.git

2. **Abrir el proyecto**
  En Visual Studio Code u otro editor de tu preferencia.

3. **Ejecutar la página**
  Abre index.html directamente en tu navegador, o
  Usa la extensión Live Server de VS Code.

4. **Probar la calculadora**
  Escribe dos números.
  Pulsa uno de los cuatro botones: +, −, × o ÷.
  Observa el resultado que se muestra en pantalla.
